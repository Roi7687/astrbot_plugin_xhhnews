# astrbot_plugin_xhhnews

小黑盒「游戏发售日历」查询 AstrBot 插件。查看本周与每月的新游发售列表，
数据与小黑盒 APP 的游戏发售日历同源。

## 功能

- **本周日历** `/hbweek` — 一周内每天的新游列表，每款游戏都带玩法类型标签
- **本月日历** `/hbmonth` — 每天一行「游戏名 + 首个标签」，另附整月概览（每天几款）
- **指定月份** `/hbmonth 2026-10` — 查看任意月份
- **无需登录** — 直接调用小黑盒公开接口，不需要账号或扫码

## 安装

1. 确保 AstrBot 已安装 `httpx` 依赖
2. 将本仓库克隆到 AstrBot 插件目录：

```bash
cd /path/to/astrbot/data/plugins
git clone https://github.com/Roi7687/astrbot_plugin_xhhnews.git
```

3. 在 AstrBot 管理界面启用插件

## 命令

| 命令 | 功能 |
|------|------|
| `/hbweek` | 本周游戏发售日历 |
| `/hbmonth` | 本月游戏发售日历 |
| `/hbmonth YYYY-MM` | 指定月份的发售日历 |
| `/hbhelp` | 显示帮助 |

## 说明

- 数据来自小黑盒公开接口，与 APP「游戏发售日历」同源
- 标签取游戏的玩法类型（如 `模拟`、`动作`、`冒险`）
- 已过去日期的标签需要逐个查询游戏详情接口，首次查询会慢一些并写入本地缓存
  （`tag_cache.json`，7 天有效），之后查询会明显加快
- 个别主机游戏接口没有玩法标签，此时显示平台（`PC` / `主机` / `手机`）
- 请合理控制调用频率，短时间内大量请求可能被服务端限流
